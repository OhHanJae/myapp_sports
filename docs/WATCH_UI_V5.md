## 무엇을 바꿨나

1. **KBO 10구단 로고** — KBO 공식 스코어보드가 사용하는 `KBO_IMAGE/emblem/regular/2026/emblem_<코드>.png` CDN에서 가져옵니다. 휴대폰·워치 앱·워치 타일 공통. 네트워크 실패 시 기존 오프라인 배지.
2. **워치 LoL 타일 팀 로고** — PandaScore `logoUrl`을 80×80 PNG 인라인 이미지로 가져와 Tile Resource에 넣습니다. 원본 URL과 게임 ID에 따라 리소스 버전을 변경하며, 경기를 바꾸면 두 팀의 로고도 갱신됩니다. 로고 없는 팀/오프라인에서는 로컬 팀 배지(약칭 매핑 포함)로 대체합니다. 타일의 이미지 요청은 백그라운드 스레드에서 처리합니다.
3. **회전 베젤 스크롤** — Compose `LazyColumn`에 포커스·rotary 이벤트를 연결하고 감도를 55%로 완화했습니다. 화면/탭 전환 시 목록 최상단으로 이동해 입력 포커스를 다시 획득합니다. 실제 반응 속도와 감도는 워치 하드웨어 설정에 영향을 받을 수 있습니다.
4. **LoL 화면 안정화** — 워치 INTERNET 권한 추가, 무거운 `SubcomposeAsyncImage` 대신 `AsyncImage`+오프라인 대체 이미지, 경기·대진 중복 lazy key 제거. 이 조치로 스크롤 시 문제를 유발할 수 있는 경로를 완화했지만, **이전 강제 종료의 정확한 원인은 로그캣이 없으므로 단정하지 않습니다.**
5. **LoL 통합 화면** — 워치에서 LCK/MSI/EWC/WORLDS/FST 선택 UI 제거. 오늘 LIVE 경기(Gen.G LIVE 우선) → 오늘 예정 → 당일 종료 → 가장 가까운 다음 경기 우선으로 한 화면에 표시합니다. 순위/대진은 자동으로 해당 경기가 속한 대회를 보여줍니다.
6. **워치 설정** — 화면 맨 아래 **⚙ 설정 · 테마 변경**. 표시 모드(시스템/다크/라이트)와 강조색(자동/블루/그린/퍼플/오렌지/핑크) 저장. `watch_theme`/`watch_accent`에 별도 저장해 폰 데이터 동기화로 덮어쓰지 않습니다. 워치 타일 강조색에도 반영합니다.

## 설치 및 확인

1. Android Studio에서 `master` 업데이트: `git pull origin master`.
2. `phone` 및 `wear` 앱을 최신 APK로 빌드·설치. 워치에 Wi-Fi/전화 연동 인터넷 연결이 있어야 실제 온라인 로고를 받아올 수 있습니다.
3. 워치 KBO 화면에서 삼성·다른 구단 로고 확인.
4. 워치 LoL 화면에서 대회 선택이 제거되고 현재 진행 중인 경기 대회로 자동 전환하는지 확인.
5. 로테이팅 베젤을 위·아래로 돌려 스크롤, 화면 맨 아래 설정에서 테마 선택.
6. LoL 타일을 다시 추가하거나 전송 데이터 갱신 후, 팀 로고 표시 확인. 새 타일 리소스의 첫 다운로드는 네트워크 상태에 따라 늦거나 기본 배지로 보일 수 있습니다.

## 다시 앱이 종료된다면

워치가 디버깅 장치에 연결된 상태에서:

```powershell
# PowerShell에서 ADB 실행 파일 경로
$adb = "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"
& $adb devices -l

# 특정 워치를 지정해 강제 종료 예외 확인
& $adb -s WATCH_DEVICE_ID logcat -d -t 400 AndroidRuntime:E
```

`WATCH_DEVICE_ID`는 `adb devices -l`에 나온 실제 워치 ID로 교체. 강제 종료 시점의 `FATAL EXCEPTION`, `Caused by`, 워치 API 버전, 최신 APK 설치 여부가 중요합니다. 구단/팀 이미지 URL에는 개인 API 토큰을 넣지 않습니다.

## 저작권과 데이터

KBO 구단 문양과 e스포츠 로고는 각 상표권자 또는 이미지 공급자의 재산이며, 프로젝트에서는 출처가 제공하는 **원본 URL을 표시**합니다. 앱을 외부에 배포할 때는 로고 재사용·표시 정책을 확인하세요. 이미지가 서버에서 제공되지 않으면 가짜 공식 로고를 만들어 넣지 않습니다.

Cloudflare Worker API는 이번 워치 UI 변경을 위해 재배포할 필요가 없으며, 기존 `/feed.json`과 `/live.json` URL은 유지됩니다.
